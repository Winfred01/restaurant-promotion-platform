# Dashboard font

IBM Plex Sans, Latin variable WOFF2 (weights 400–600), 45,712 bytes.
Self-hosted only; the dashboard makes no request to a font CDN at runtime.

- Font source: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600&display=swap)
- Binary: [Google Fonts WOFF2](https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYY.woff2)
- License: [SIL Open Font License](OFL.txt), from the [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/ibmplexsans).

Glyphs outside this subset use the system sans-serif fallback. No font or runtime dependency was added to package.json.
